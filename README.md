# CT-to-Fluoroscopy 2D/3D Registration for TAVI and Spine Procedures

Learning-based 2D/3D registration of a preoperative CT to intraoperative fluoroscopy (X-ray), with two application settings:

- **TAVI** (Transcatheter Aortic Valve Implantation): training data is generated by simulating interventional instruments (catheter, guidewire, valve) inside the CT before rendering DRRs.
- **Spine**: a cascade of bone extraction, pose regression and pose refinement, trained on DRRs rendered from the masked CT.

## Overview

### 1. TAVI: DRR generation with simulated instruments

![TAVI instruments simulation](assets/instruments.png)

Training pairs are synthesized from a CT volume in four steps:

- **A) 3D aorta centerline.** The centerline is extracted from the segmented aorta.
- **B) 3D centerline displacement.** The centerline is displaced in 3D to vary the instrument trajectory inside the vessel.
- **C) Instruments simulation.** Instruments are generated parametrically along the centerline:
  - *Catheter*: follows the centerline.
  - *Guidewire*: a straight segment (tangent `tg`, normal `n`, max length) followed by a distal curve.
  - *Valve*: a stent-like mesh defined by three radii (`r1`, `r2`, `r3`), a waist height and an overall height.
- **D) DRR generation.** The simulated instruments are inserted into the CT volume, and the X-ray simulator renders a DRR with instruments, which goes into the training set.

### 2. Spine: cascaded registration pipeline

![Spine registration pipeline](assets/pipeline_full.png)

- **CT masking.** The CT is reduced to the spine (bone segmentation, then masked volume) before DRR rendering.
- **Bone extraction model.** An HRNet-based network predicts a bone-only image from the input X-ray, trained with a gradient-NCC loss (`L_gradNCC`) against the bone DRR.
- **Pose regressor (CNN₁).** Regresses an initial pose `P_init` from the predicted bone image, trained with a mean projection distance loss (`L_mPD₁`) against `P_GT`.
- **X-ray simulator.** Renders a DRR of the masked CT at `P_init`.
- **Registration model (CNN₂).** Takes the predicted bones and the DRR at `P_init`, and regresses a pose correction `P_Δ`, trained with `L_mPD₂`. The final pose is `P̂`, obtained by composing `P_init` with `P_Δ`.

## Repository structure

| Path | Description |
|---|---|
| `CTpreprocessing/` | CT preprocessing scripts (segmentation, cropping, masking) |
| `hu_to_mu.py` | Conversion of CT Hounsfield units to linear attenuation coefficients for DRR rendering |
| `intruments_vol_generation.py` | Generation of CT volumes containing the simulated instruments |
| `simulation_instruments_TAVI.py` | Parametric simulation of catheter, guidewire and valve along the aortic centerline |
| `models.py` | Network architectures (HRNet bone extraction, pose regressor, registration model) |
| `train_bones.py` | Training of the bone extraction model |
| `train_cascade_encoder_decoder.py` | Training of the cascaded pose regression / registration models |
| `domain_adap_tavi.py` | Domain adaptation for TAVI |
| `opt_tavi.py` | Optimization-based registration for TAVI |
| `test_TAVI_multi_patients.py` | Evaluation on multiple TAVI patients |
| `checkpoint.py` | Checkpoint saving and loading |
| `utils.py` | Shared utilities |

## Usage

Suggested order for a full run:

```bash
# 1. Preprocess the CT volumes
#    see CTpreprocessing/

# 2. Convert HU to attenuation coefficients
python hu_to_mu.py

# 3. Simulate instruments and generate the volumes (TAVI)
python intruments_vol_generation.py

# 4. Train the bone extraction model
python train_bones.py

# 5. Train the cascaded pose regressor / registration models
python train_cascade_encoder_decoder.py

# 6. Evaluate on multiple patients (TAVI)
python test_TAVI_multi_patients.py
```
